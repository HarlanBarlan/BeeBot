# Bridge probes

Template images used to locate UI buttons for scripted bridges.

Snip each with `snip_template.py`. Snip TIGHT rectangles around the
button (a few px of frame is fine, but avoid capturing surrounding
buttons or text).

## Required for `return_to_hive` bridge

- `reset_character_button.png` — the "Reset Character" button inside
  the Roblox menu that appears after pressing ESC.
- `reset_character_confirm.png` — the confirmation button that appears
  after clicking Reset Character (usually says "Reset" or similar).

Snip both while the Roblox menu / confirmation dialog is visible.
